# F1 — True peer set is small

**Hypothesis 1:** True peer set is small (<12 named studios); most “competitors” are single-product specialists Unloved should not mirror at holding level.

**Verdict:** Confirmed.

**Claim:** At holding-company unit of analysis, Unloved has fewer than a dozen named peers. Vertical specialists (BookBolt, DeleteMe, Google Translate, Acquire.com) are market pressure, not peers.

## Upper-bound archetypes (4) — not size-matched

Tiny Ltd, Awesome Motive, saas.group, Automattic. Useful for failure modes. Wrong scale and (except AM's WP glue) wrong operating model.

## Thin / excluded

2026-era sites (Stakyo, Furiaa, UTLTY, Bootstrapped Ventures) appeared in search as “indie holdcos” with little independent press. Per plan, not treated as peers.
